How the gallery stays safe

  • Only wallpaper files. Shader code, videos, GIFs and pictures. Never programs or scripts.
  • Shaders can't reach your files. They run on the graphics card and can only work out pixel colours.
  • Every file is tested with livewall itself, and turned down if it is broken or too heavy for an everyday wallpaper.
  • Every file is scanned for viruses, and videos, GIFs and pictures are rebuilt, which drops hidden data such as location.
  • A person approves every wallpaper, and livewall checks each download's fingerprint before using it.

This site has no accounts, no ads, no cookies and no tracking. Likes are upvotes on GitHub, counted a few times a day.
